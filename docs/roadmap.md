# Roadmap

## Phase 0: scaffold and contracts

- establish package layout
- document the IR and feature contract
- choose parser boundary
- define the first extractor slice

## Phase 1: minimal end-to-end pipeline

- load `MusicXML` and `MXL`
- normalize score objects
- assign hands conservatively
- extract direct descriptors
- export JSON

## Phase 2: validation and robustness

- expand fixtures
- add regression baselines
- refine diagnostics
- harden edge-case handling

## Phase 3: richer musical features

- articulation and dynamics
- pedaling
- harmony and structure
- more sophisticated hotspot ranking

## Phase 4: research-driven layers

- pedagogy-weighted summaries
- personalized difficulty logic
- advanced proxies
- optional learned models
