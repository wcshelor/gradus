# Bibliography

This directory contains the repository's shareable source records.

- `library.xlsx` is the working source catalog, theme registry, tag registry,
  and search log.
- `references.bib` is available for citation tooling and the eventual thesis.

The workbook is the organizational inventory; the BibTeX file is the citation
record. They may overlap, but neither should contain copyrighted full text.

## Workbook sheets

- `Sources` stores one source per row, including themes, tags, reading status,
  priority, local paths, and discovery provenance.
- `Themes` defines the broad search and synthesis lenses.
- `Tags` defines reusable multidimensional tag IDs.
- `Search Log` records queries, databases, filters, and screening counts so
  literature searches can be revisited.

Use semicolons between multiple secondary themes or tags. Keep theme and tag
IDs aligned with their registry sheets.
