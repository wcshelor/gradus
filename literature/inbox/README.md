# Literature inbox

This is the temporary intake area for promising sources found during searches,
recommendations, citation chasing, or conversations.

A source does not need complete metadata or tags before it is captured. Add it
to the `Sources` sheet of `../bibliography/library.xlsx` with reading status
`found` or `queued`, record where it was discovered, and tag only what can be
supported from the available title, abstract, or metadata.

During triage:

1. confirm the source identity and stable URL or DOI;
2. assign a primary theme;
3. add supported secondary themes and tags;
4. set priority and reading status;
5. decide whether a local paper copy and detailed note are needed;
6. record exclusion reasons rather than deleting a considered source.

Do not infer methods, populations, results, or pedagogical relevance from a
title alone when the abstract or paper is unavailable.
