# Literature themes

Themes are broad lenses for planning searches and synthesizing bodies of work.
They are not exclusive folders: each source has one primary theme and may have
several secondary themes.

The theme registry lives on the `Themes` sheet of
`../bibliography/library.xlsx`. Each theme has:

- a stable `theme_id`;
- a human-readable label;
- a deliberately broad scope;
- guiding search questions;
- indicative inclusion and exclusion terms;
- a status such as `active` or `watch`.

The initial themes are:

- `piece-learning-pedagogy`
- `historical-pedagogy-etudes`
- `pedagogy-practice`
- `technical-demands`
- `score-understanding`
- `learning-sciences`
- `adaptive-support`
- `ai-learning-systems`
- `generated-material`
- `human-ai-interaction`
- `evaluation-responsibility`
- `performance-feedback`

These are starting lenses, not a frozen thesis structure. Add, merge, rename, or
retire themes when the literature reveals a better organization. Keep the ID
stable after papers have been assigned to it; record a replacement instead of
silently changing its meaning.

The active brief for the thesis's central teaching problem is
[`piece_learning_pedagogy.md`](piece_learning_pedagogy.md).
The historical and étude branch is documented in
[`historical_pedagogy_etudes.md`](historical_pedagogy_etudes.md).

## Theme briefs

When a theme becomes active enough to deserve its own search strategy, create a
Markdown brief here using `../templates/theme_brief.md`. A brief can record:

- the question driving the search;
- vocabulary and adjacent fields;
- useful databases or venues;
- landmark sources;
- inclusion and exclusion decisions;
- gaps, disagreements, and next searches.
