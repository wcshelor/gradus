## Contracts added or changed

- **New T01.1:** `ScorePosition` (quarters, measure_index, measure_number, offset_in_measure, voice, staff, hand), frozen, `schema_version=score_position.v1`.
- **New T01.1:** `ScoreInterval` (start, end as ScorePosition, half-open, duration), `schema_version=score_interval.v1`.
- **New T01.1:** Fraction serialization canonical `{"numerator":int,"denominator":int}` (accepts `"num/den"` defensively, rejects float).
- **New T01.2:** `SourceKind` enum (written_note, logical_note, rest, measure, direction, clef, onset_group) and `SourceRef(id, kind)` frozen, `schema_version=source_ref.v1`.

- Version policy: `SUPPORTED_*_VERSIONS` singletons; unsupported raises `ValueError`.
- No passage/view container yet (T01.4).

## Representative evidence

```python
# T01.1
p = ScorePosition(quarters=Fraction(7,4), measure_index=2, measure_number="3",
                  offset_in_measure=Fraction(3,4), voice="1", staff=1, hand="right")
iv = ScoreInterval(start=..., end=...)  # start.quarters < end.quarters enforced
d = iv.to_dict()  # {"schema_version":"score_interval.v1","start":{...},"end":{...}}
assert ScoreInterval.from_dict(d) == iv
assert json.dumps(d, sort_keys=True) == json.dumps(ScoreInterval.from_dict(d).to_dict(), sort_keys=True)
assert not iv.contains_quarters(iv.end.quarters) # half-open

# T01.2
ref = SourceRef(id="n1", kind=SourceKind.WRITTEN_NOTE)
assert resolve_ref(score, ref).note_id == "n1"
assert SourceRef.from_dict(ref.to_dict()) == ref
assert not is_resolvable(score, SourceRef(id="n9999", kind=SourceKind.WRITTEN_NOTE))
# deterministic: same file twice → same ids
assert sorted(n.note_id for n in build_score_ir(load_musicxml_document(p)).written_notes) == \
       sorted(n.note_id for n in build_score_ir(load_musicxml_document(p)).written_notes)
```

Golden payloads not frozen beyond unit assertions; WP-01 will freeze one compact JSON per T01.4.

## Unsupported and ambiguous cases

- **T01.1:** Fraction rejects `float` (`lossy float fraction rejected`); `ScoreInterval` rejects empty/inverted; `measure_index` inconsistent raises; unsupported `schema_version` raises.
- **T01.2:** `SourceRef` rejects empty id, unknown kind, unsupported version; `resolve_ref` returns `None` for missing (no silent valid), wrong kind does not cross-resolve; `ONSET_GROUP` intentionally unsupported → `None` until view semantics define it; no XML mutation.
