## Representative evidence

```python
# T01.1
iv = ScoreInterval(start=ScorePosition(quarters=Fraction(0,1), measure_index=0, offset_in_measure=Fraction(0,1)),
                   end=ScorePosition(quarters=Fraction(2,1), measure_index=0, offset_in_measure=Fraction(0,1)))
assert not iv.contains_quarters(iv.end.quarters)  # half-open

# T01.2
ref = SourceRef(id="n1", kind=SourceKind.WRITTEN_NOTE)
assert resolve_ref(score, ref).note_id == "n1"
assert SourceRef.from_dict(ref.to_dict()) == ref

# T01.3
d = Diagnostic(code="hand_inferred", severity=Severity.INFO, message="hand inferred",
               context={"z":1,"a":2}, source_refs=(ref,))
assert list(d.to_dict()["context"].keys()) == ["a","z"]  # deterministic
assert Diagnostic.from_dict(d.to_dict()) == d

# T01.4
p = Passage(passage_id="test.passage.1", score_id="score.test",
            start=_pos(Fraction(0,1)), end=_pos(Fraction(4,1)),
            purpose=PassagePurpose.DETECTION, method_id="m", method_version="1.0",
            event_refs=(ref,), omissions=("non-target-hand",))
assert json.dumps(p.to_dict(), sort_keys=True) == json.dumps(Passage.from_dict(p.to_dict()).to_dict(), sort_keys=True)
# compact minimal passage omits optional fields
compact = Passage(passage_id="c", score_id="s", start=_pos(Fraction(0,1)), end=_pos(Fraction(1,1)),
                  purpose=PassagePurpose.PRACTICE, method_id="m", method_version="v1")
assert "parent_id" not in compact.to_dict()

v = View(view_type=ViewType.LOGICAL_ATTACK_STREAM, source_passage_id="test.passage.1",
         method_id="m", method_version="v1", ordering="onset", confidence=0.9)
assert View.from_dict(v.to_dict()) == v
```

## Unsupported and ambiguous cases

- **T01.1:** Fraction float rejected; interval empty/inverted and measure_index inconsistent rejected; unsupported schema_version raises.
- **T01.2:** empty id/unknown kind/unsupported version rejected; missing ref → `None`; `ONSET_GROUP` → `None`; cross-kind not resolved; no XML mutation.
- **T01.3:** unknown `Severity` or bad `source_refs` (bogus kind) raises; unsupported `diagnostic.v1` raises; missing code/severity/message raises; no layer-specific catalogs created.
- **T01.4:** unknown `PassagePurpose`/`ViewType` raises; unsupported `passage.v1`/`view.v1` raises; empty/too-long ID, `start>=end`, bad confidence (>1) raises; no diagnosis/strategy fields.
