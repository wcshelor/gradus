# Retired Artifact Archive

This tree contains generated evidence that is no longer part of the active
investigation loop.

Archived groups currently include:

- `cipi_og_export/`: the old CIPI survey and feature-candidate exploration
  outputs
- `oktav_testset/`: superseded Oktav export experiments from the earlier test
  set naming
- `oktav_dataset/og_export/`: superseded Oktav smoke and manual export runs
- `oktav_dataset/slowdown_diagnostics/`: superseded Oktav smoke diagnostics
- `scoreanalyzer_failure_taxonomy/cipi_failure_probe/`: the historical CIPI
  window-failure taxonomy run

Keep new active evidence out of this tree. If a retired run becomes relevant
again, rerun it in the active tree rather than moving files back by hand.
