# Inspection Candidates

This folder holds a curated shortlist of pieces chosen from the latest Oktav and CIPI
9-feature clustering runs for manual visual inspection.

The shortlist is organized by PCA quadrant:

- `high_high/`
- `high_low/`
- `low_high/`
- `low_low/`

Each quadrant folder contains one CSV per dataset (`oktav.csv` and `cipi.csv`) with the
pieces ranked by distance from the origin in that quadrant.

Note: PCA sign is arbitrary, so the labels here are relative to the current run.
